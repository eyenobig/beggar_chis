# 烧丐（Chis Flasher）

[English](../../README.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Русский](ru.md)

用于将 **GB / GBC / GBA** ROM 写入 [ChisFlash](https://github.com/ChisBread/ChisFlash) 烧录卡的桌面工具。

## 功能

- 向 ChisFlash 卡带烧录 GB / GBC / GBA ROM
- 存档读取 / 写入 / 擦除 / 校验
- 识别卡带信息，支持多台烧录器
- 可选 SkyEmu DirectPlay 直接读卡运行

## GBMake

配合 **[GBMake](https://www.gbmake.com)**，支持卡带全客制化复刻：

- **贴纸** — 标签 / 盒绘设计与制作
- **PCB** — 客制卡带电路板
- **外壳** — 客制卡带壳

从画面到硬件一站式定制。
