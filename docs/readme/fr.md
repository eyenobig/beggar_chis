# Chis Flasher

[English](../../README.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Русский](ru.md)

Application bureau pour écrire des ROMs **GB / GBC / GBA** sur des cartouches [ChisFlash](https://github.com/ChisBread/ChisFlash).

## Fonctions

- Écriture ROM GB / GBC / GBA vers ChisFlash
- Lecture / écriture / effacement / vérification des sauvegardes
- Identification de cartouche, multi-flashers
- SkyEmu DirectPlay (optionnel)

## GBMake

Avec **[GBMake](https://www.gbmake.com)**, reproduisez des cartouches entièrement sur mesure :

- **Stickers** — labels / jaquettes
- **PCB** — circuits imprimés personnalisés
- **Coques** — boîtiers personnalisés

Personnalisation de bout en bout, de l’artwork au hardware.
