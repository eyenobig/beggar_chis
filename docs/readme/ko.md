# Chis Flasher

[English](../../README.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Русский](ru.md)

[ChisFlash](https://github.com/ChisBread/ChisFlash) 카트리지에 **GB / GBC / GBA** ROM을 기록하는 데스크톱 도구입니다.

## 기능

- ChisFlash에 ROM 쓰기 (GB / GBC / GBA)
- 세이브 읽기 / 쓰기 / 지우기 / 검증
- 카트리지 인식, 다중 라이터 지원
- SkyEmu DirectPlay (선택)

## GBMake

**[GBMake](https://www.gbmake.com)**와 함께 카트리지를 풀 커스텀으로 복제할 수 있습니다:

- **스티커** — 라벨 / 박스 아트
- **PCB** — 커스텀 기판
- **셸** — 커스텀 외장

아트워크부터 하드웨어까지 원스톱 커스터마이징.
