# Chis Flasher

[English](../../README.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Русский](ru.md)

[ChisFlash](https://github.com/ChisBread/ChisFlash) カートリッジへ **GB / GBC / GBA** ROM を書き込むデスクトップツールです。

## 機能

- ChisFlash への ROM 書き込み（GB / GBC / GBA）
- セーブの読み出し / 書き込み / 消去 / 検証
- カートリッジ情報の認識、複数ライター対応
- SkyEmu DirectPlay（任意）

## GBMake

**[GBMake](https://www.gbmake.com)** と組み合わせて、カートリッジをフルカスタムで復刻できます：

- **ステッカー** — ラベル / パッケージアート
- **PCB** — カスタム基板
- **シェル** — カスタム筐体

アートからハードウェアまで一気通貫のカスタマイズ。
