# Chis Flasher

[English](../../README.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Русский](ru.md)

Desktop-App zum Brennen von **GB- / GBC- / GBA-ROMs** auf [ChisFlash](https://github.com/ChisBread/ChisFlash)-Module.

## Funktionen

- ROMs auf ChisFlash brennen (GB / GBC / GBA)
- Spielstände lesen / schreiben / löschen / prüfen
- Modul erkennen, mehrere Brenner
- SkyEmu DirectPlay (optional)

## GBMake

Mit **[GBMake](https://www.gbmake.com)** können Sie Module vollständig nach Maß reproduzieren:

- **Sticker** — Labels / Cover-Art
- **PCB** — individuelle Platinen
- **Gehäuse** — individuelle Modulgehäuse

End-to-end-Customizing von Artwork bis Hardware.
