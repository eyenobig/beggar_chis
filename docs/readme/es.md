# Chis Flasher

[English](../../README.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Русский](ru.md)

App de escritorio para grabar ROMs de **GB / GBC / GBA** en cartuchos [ChisFlash](https://github.com/ChisBread/ChisFlash).

## Funciones

- Grabar ROMs GB / GBC / GBA en ChisFlash
- Leer / escribir / borrar / verificar partidas
- Identificar cartuchos y usar varias grabadoras
- SkyEmu DirectPlay (opcional)

## GBMake

Con **[GBMake](https://www.gbmake.com)** puedes reproducir cartuchos a medida:

- **Stickers** — etiquetas / arte de caja
- **PCB** — placas personalizadas
- **Carcasas** — carcasas personalizadas

Personalización de punta a punta, del arte al hardware.
