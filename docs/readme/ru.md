# Chis Flasher

[English](../../README.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Русский](ru.md)

Настольное приложение для записи ROM **GB / GBC / GBA** на картриджи [ChisFlash](https://github.com/ChisBread/ChisFlash).

## Возможности

- Запись ROM на ChisFlash (GB / GBC / GBA)
- Чтение / запись / стирание / проверка сохранений
- Распознавание картриджа, несколько программаторов
- SkyEmu DirectPlay (опционально)

## GBMake

Вместе с **[GBMake](https://www.gbmake.com)** — полная кастомная реплика картриджа:

- **Стикеры** — этикетки / оформление коробки
- **PCB** — платы на заказ
- **Корпуса** — корпуса на заказ

Кастомизация от арта до железа в одном месте.
